# Changelog

All notable changes to **API Learn** will be documented in this file.

The project is actively developed, so new endpoints, scraping scenarios, SOAP operations, documentation improvements, and platform behavior may be added over time.

---

## 2026-09

### Added

* Public GitHub repository for API Learn
* GitHub Issues with structured templates for:

  * general bugs
  * REST API issues
  * SOAP API issues
  * scraping and browser automation issues
* GitHub Discussions for questions, ideas, and community feedback
* Public project documentation in `README.md`
* `CONTRIBUTING.md`
* `SECURITY.md`

### Documentation

* Added public links to:

  * main platform
  * REST API documentation
  * SOAP documentation
  * WSDL
  * YouTube channel
* Clarified that the application source code is private
* Added guidance for responsible use and protection of sensitive data

## Platform highlights

API Learn currently includes:

* 370+ fake e-commerce products
* Web scraping practice pages
* Server-Side Rendered catalog pages
* AJAX HTML catalog loading
* AJAX JSON catalog loading
* Infinite Scroll
* REST API
* Swagger / OpenAPI documentation
* SOAP 1.1 API
* WSDL 1.1
* XML Schema validation
* SOAP Faults
* WS-Security UsernameToken
* Token authentication
* JWT authentication
* User registration and login
* User profiles
* Shopping carts
* Orders
* Pagination
* Filtering
* Sorting
* Rate limiting
* HTTP caching behavior
* Educational scraping detection
* Browser automation scenarios
* Periodic reset of temporary application data

## Notes

API Learn is a live educational service rather than a published source-code project.

This changelog documents meaningful changes to the public platform, documentation, APIs, educational scenarios, and community resources.

Minor internal implementation changes may not be listed.
